Самая частая: type. Примеры выше позволяют проверить полные и частичные имена. Boundary требует проверки границ, type — неоднозначных контекстов, missed — редких и обрезанных сущностей, spurious — обычных слов с заглавной буквой. Автоматическая разметка может ошибаться, но без ручной проверки конкретные расхождения не объявляем её ошибками. Для type сначала проверим примеры, затем добавим адресные данные; единица подсчёта следует контракту задания, не one-to-one matching.
