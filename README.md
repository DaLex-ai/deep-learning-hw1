# Домашнее задание №1 — Глубокое обучение

Работу выполнил Алёшкин Дмитрий, группа J3311, ИСУ 464975.

**Тема:** Свёрточные нейронные сети, обучение глубоких моделей и устойчивость к adversarial-атакам.

Репозиторий содержит выполненное домашнее задание по глубокому обучению с использованием Python и PyTorch.

В работе реализованы основные компоненты свёрточных нейронных сетей, исследованы методы оптимизации и обучения глубоких архитектур, проведены эксперименты с adversarial-атаками и методами повышения устойчивости моделей.

Все основные эксперименты выполнены с сохранением результатов, графиков, метрик и весов обученных моделей.

## 1. Содержание работы

### Часть 1. Свёрточные операции

- Реализация свёртки без использования готовых свёрточных слоёв PyTorch.
- Реализация обратного распространения градиентов через свёртку.
- Исследование receptive field с использованием autograd.
- Анализ effective receptive field.

### Часть 2. Batch Normalization

- Реализация Batch Normalization.
- Проверка корректности вычислений и градиентов.
- Слияние свёрточного слоя и Batch Normalization для инференса.

### Часть 3. Оптимизация нейронных сетей

- Исследование инициализации весов.
- Собственная реализация оптимизатора AdamW.
- Реализация cosine learning rate schedule.

### Часть 4. ResNet и CIFAR-10

- Реализация архитектуры ResNet-20.
- Обучение модели на CIFAR-10.
- Анализ динамики функции потерь и точности.
- Сравнение архитектур с residual connections и без них.
- Исследование влияния глубины сети на качество обучения.

### Часть 5. Adversarial Attacks

- Реализация PGD-атаки с ограничением по норме L2.
- Исследование зависимости точности классификации от силы атаки.
- Реализация targeted adversarial attack.

**Выбранная дополнительная ветка:** 5.2 — Targeted Attack.

### Часть 6. Adversarial Training

- Обучение стандартной модели на FashionMNIST.
- Реализация adversarial training с использованием PGD.
- Сравнение качества стандартной и робастной моделей.
- Оценка устойчивости к FGSM и PGD-атакам.
- Диагностика корректности оценки adversarial robustness.
- Исследование градиентов по входным изображениям.

## 2. Результаты экспериментов

### 2.1. Обучение ResNet-20 на CIFAR-10

Модель ResNet-20 обучалась на датасете CIFAR-10 в течение 20 эпох.

В экспериментах использовались оптимизаторы AdamW и Muon.

| Модель | Точность на тестовой выборке |
|---|---:|
| ResNet-20 (AdamW) | 82,70% |
| ResNet-20 (Muon) | 85,15% |

В проведённом эксперименте использование Muon позволило получить более высокую итоговую точность по сравнению с AdamW.

Дополнительно выполнены эксперименты с архитектурами без residual connections.

### 2.2. Устойчивость моделей на FashionMNIST

Проведено сравнение стандартного обучения и PGD adversarial training.

| Метод обучения | Clean Accuracy | PGD Accuracy (ε = 0.1) |
|---|---:|---:|
| Стандартное обучение | 91,7% | 0,5% |
| PGD Adversarial Training | 84,5% | 71,9% |

Метрики рассчитаны для используемой в ноутбуке конфигурации атак и тестовой подвыборки из 1000 изображений.

**Основные наблюдения:**

- Стандартная модель показывает высокую точность на исходных изображениях, но практически полностью теряет устойчивость при PGD-атаке.
- Adversarial training существенно повышает устойчивость модели.
- Увеличение робастности сопровождается снижением точности на исходных изображениях.
- Результаты демонстрируют компромисс между стандартным качеством классификации и adversarial robustness.

Подробные кривые обучения и результаты проверок находятся в ноутбуке и файле `artifacts/metrics.json`.

## 5. Установка и запуск

### Требования

Для запуска рекомендуется Python 3.13 и среда с поддержкой CUDA.

Для вычислительно затратных экспериментов, особенно PGD adversarial training, рекомендуется GPU.

### Клонирование репозитория

```bash
git clone https://github.com/DaLex-ai/deep-learning-hw1.git
cd deep-learning-hw1
```

### Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

Зависимости включают PyTorch, torchvision, NumPy, Matplotlib и инструменты для работы с Jupyter Notebook.

### Запуск ноутбука

Откройте `hw1_deep_learning.ipynb` в Google Colab, Jupyter Notebook или VS Code.

Выполняйте ячейки последовательно.

Датасеты CIFAR-10 и FashionMNIST автоматически загружаются при первом запуске. Для первоначальной загрузки необходимо подключение к интернету.

Полное повторное выполнение всех экспериментов может потребовать значительного времени, поэтому в репозитории также представлены сохранённые результаты обучения и веса моделей.
